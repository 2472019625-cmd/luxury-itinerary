# 旅行实体名称统一与多语言客户展示

状态：已实施，待线上真实项目人工复核

## 本轮边界

- 建立通用 Travel Entity Registry 与 locale resolver；肯尼亚、坦桑尼亚仅作为首批静态 seed data 的业务来源，不在解析程序中硬编码国家逻辑。
- 保留 `officialName/canonicalName/routeNodes/searchIntent` 的内部精确语义，不修改 Parser、Planner 事实、Facts Research、Image Search、知识库或 Pipeline Stage。
- 客户展示复用 `shortName/hotelShortName`，Step4 与最终 customer render 共用同一 resolver。
- Copy Skill 只接受已解析展示名，不承担自由翻译；Visual Card 对已识别实体增加确定性名称门禁。
