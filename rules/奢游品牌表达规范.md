# 奢游国际品牌表达与行程生成规范

> **历史迁移文件**：当前有效内容已迁入 `03-品牌文案与模块内容.md`，其中事实、图片、视觉和运行边界分别迁入 02、04、05、06。本文件仅供迁移核对与历史追溯，不再作为当前执行依据。

版本：1.1  
适用范围：客户版行程长图、定制方案 PDF、酒店与体验介绍、产品亮点、费用说明、出行提醒、报价表转成品长图。

## 一、总原则

客户版行程不是“报价表美化”，而是“高端旅行产品说明书 + 购买欲激发材料”。每个板块必须同时完成三件事：

1. 让客户看完产生“我想亲自抵达这里”的向往。
2. 让客户理解钱花在哪里，以及奢游做了哪些专业设计。
3. 把费用、安全和自然边界说清楚，但不能让客户第一眼像在看免责条款。

统一表达顺序：

> 先吸引 → 再说明价值 → 再交代安排 → 最后温和兜底

任何正文都不能只剩理性说明；任何营销表达也不能越过事实和履约边界。保留奢游旧版 PDF 的情绪张力，用新版结构控制信息密度、履约边界和视觉高级感。

## 二、品牌人格与语气

### 1. 品牌人格

- 懂顶级旅行资源的产品经理，而不是导游词撰写者。
- 能把复杂旅程安排得从容的私人度假管家。
- 对目的地有见识、有审美，也知道客户真正担心什么。
- 热情但不喧闹，华丽但不廉价，专业但不冷硬。

### 2. 可保留的奢游式情绪词

- 野奢、私享、稀缺、从容、深入、抵达、守候、追踪、沉浸、俯瞰、邂逅、珍藏。
- 黄金位置、旷野深处、草原腹地、第一排视角、上帝视角、自然剧场、印度洋时光。
- 人生必见、终生难忘、最壮观、最惊心动魄、绝世景观、天国之渡、动物王国。

这些词可以使用，而且应当保留旧版行程的吸引力。使用原则是：一段只围绕一个情绪高潮展开，必须有具体路线、季节、酒店、活动或体验支撑，不能连续堆叠空泛最高级。

### 3. 禁止形成的语气

- 平铺直叙的说明书口吻：如“前往景点，参观结束后返回酒店”。
- 百科口吻：如只写面积、物种数量、行政区划，却没有客户体验。
- 廉价促销口吻：如“超值、必冲、打卡、网红爆款、性价比拉满”。
- 内部操作口吻：如“原始资料照片、供应商报价、利润、加价、成本”。
- 推卸责任口吻：如“不能保证、后果自负、一切以现场为准”。

## 三、客户版长图固定结构

长图推荐顺序固定为：

1. 封面。
2. 定制师名片。
3. 产品亮点。
4. 行程总览。
5. 臻选下榻。
6. 特色餐饮。
7. 全程交通。
8. 每日行程细节。
9. 费用包含 / 费用不含。
10. 预订流程 / 资金安全。
11. 注意事项。
12. 固定品牌页脚。

“定制师”必须放在前段，因为它体现奢游的服务感；这是未来应用中由每位定制师自行配置的个人名片位。缺少真实姓名与头像时，使用默认头像和“定制师名字 | 资深定制师”作为非真人占位，默认服务收束语使用“让你的旅行 有品质 也有范儿”。不写联系方式待补充，不得编造真人、年限、订单数或好评率。

## 四、板块生成规则

### 0. 封面标题与副标题

封面主标题必须一行呈现，让客户第一眼知道“去哪、几天几晚、是什么性质的行程”。标题结构优先使用：

> 目的地 + 天数晚数 + 产品级别/旅行方式 + 定制游属性 + 主题

示例：

> 肯尼亚8天7晚顶奢Safari定制游

不要只写“肯尼亚顶奢 Safari”这类泛主题标题；也不要把酒店清单当作封面副标题。酒店品牌可以在产品亮点或住宿板块展开。

封面标题和副标题不使用具体人数或组团形态制造产品限制感，例如“2人独立成团 / 定制团 / 私家团”。具体人数放在出行信息卡中，“一家一团”等服务承诺放在产品亮点中；封面主标题优先使用“定制游 / 深度游 / Safari定制游”等产品形态表达。

封面副标题负责写“为什么值得去、如何被定制、旅程画面是什么”，应包含路线气质、核心体验和定制服务感。推荐结构：

> 以私家定制的出行节奏 + 串联哪些核心场景 + 如何形成一段定制旅程

副标题应是一句有画面感的客户版说明，不照搬原始表格的副标题或酒店罗列。

### 1. 产品亮点

统一使用“产品亮点”，不使用“行程亮点”。产品亮点不只是说去哪玩，而是说明为什么选择奢游和这条路线。

产品亮点由两类内容组成：

- 奢游长期成立的公司优势：一家一团、定制师 1V1、全程专属服务、专属车辆、不拼车、路线可灵活调整、优质供应链与在地资源。
- 本条路线真实存在的产品差异：园内连住、私人保护区、草原飞机、三大国家公园、迁徙带营地、特色餐饮、热气球、海岛浮潜等。

如果原始表格、旧海报或销售资料中已有“海报下方亮点 / 主推亮点 / 核心卖点”，必须优先抽取并评估。这类亮点通常是定制师已经提炼过的销售语言，可以保留其核心短标题，再扩写成客户版完整表达。不要因为要加入公司优势而覆盖掉原始销售亮点。

表达形式：

> 短标题：具体价值

每条控制在一至两行。不能所有线路都复制同一组空泛亮点，也不能只写内部服务而忽略路线本身的高光。推荐比例为 2 条奢游可复用服务优势 + 4 条本行程独有卖点；若原始海报亮点特别强，可以让本行程卖点占更高比例。

### 2. 行程总览

行程总览只负责快速建立整体认知，不重复每日细节。

应保留：

- Day 编号。
- 每日情绪主题。
- 简化路线：A → B → C。
- 必要交通提示：长车程、草原飞机、出海、轮渡等会影响体感的衔接。

应去掉：

- 每日三餐重复罗列。
- 每晚酒店全名重复堆叠。
- 太长的说明句。
- 过多标签。

视觉重点优先给“路线主线”，因为客户扫一眼最先要知道每天从哪里到哪里。每日主题作为第二层，负责告诉客户这一天的旅行意义。

### 3. 臻选下榻

住宿板块标题优先使用“臻选下榻”，也可根据版式使用“奢享下榻 / 臻选酒店”。不要使用过于普通的“精选住宿”。

每家酒店的数据源应保留：

- 中文展示名。
- 官方英文名，方便客户搜索核对。
- 住宿区域。
- 入住晚数。
- 房型。
- 餐食计划。
- 一段产品经理式推荐文案。
- 真实酒店、官方媒体或可授权图片。

客户长图酒店卡片重点展示中文展示名、官方英文名、住宿区域、入住晚数、推荐文案和体验锚点。房型、餐食计划、基本房型报价、供应商价格备注等不在酒店卡片中展示；如需对客确认，放入正式合同、确认单或费用说明的客户版边界文案中。

表达方式不要使用“为何选择 / 值得体验”问答式标签，而是直接用完整叙事证明价值：

> 住在哪里 + 为什么位置珍贵 + 酒店本身最值得体验的场景 + 它如何服务整段路线

酒店文案应通过位置、私密性、房量、景观、服务和独特体验证明“高端”，不要反复喊“顶奢”。

原始报价单或供应商表格中的酒店描述只作为事实来源，不得原样照搬进客户版。必须先完成语言转换：

- 把“设施罗列”改成“客户住进去会获得什么体验”。
- 把“地理位置说明”改成“为什么这个位置服务路线节奏”。
- 把“酒店卖点堆叠”改成“最值得被客户记住的一两个场景”。
- 把“供应商口吻 / 翻译腔 / 生硬宣传语”改成奢游的产品经理式推荐。
- 房型、餐食或替换状态作为履约事实保留在内部数据、确认单或底部统一说明里，不写进酒店卡片的情绪化推荐文案，也不以卡片标签形式突出。

推荐文案结构：

> 这家酒店处在什么位置 → 这个位置为什么珍贵 / 省心 → 客户抵达后最能感受到的场景 → 它如何承接当天或下一段行程

可使用的表达方向：

- “把清晨黄金时段留给游猎，而不是长途折返。”
- “让抵达后的第一晚从容过渡。”
- “把草原景观、营地私密性和游猎动线压缩在同一处停留里。”
- “让海岛段从赶路切换为真正的度假节奏。”

酒店状态说明统一放在板块底部：

> 所列酒店及房型以正式确认单为准；如遇满房或酒店运营调整，将安排同等级或更高标准替代，并由定制师提前沟通。

不在图片右下角显示“已确认 / 参考酒店 / 同级替换”等角标。

### 4. 特色餐饮

餐饮类独立板块固定命名为“特色餐饮”，放在“臻选下榻”之后、“全程交通”之前。它不是普通三餐清单，而是展示客户可能关注的“吃什么、在哪里吃、氛围如何”。

展示原则：

- 普通三餐只在每日细节里文字说明。
- 特色餐饮、酒店代表性餐厅、草原早餐、Boma Dinner、Bush Dinner、日落茶歇、百兽宴、海鲜餐等，可以图文展示。
- 没有菜单或菜品确认时，只写餐饮氛围和场景，不虚构具体菜名。
- 酒店官方餐厅或代表性用餐氛围图片可以用于体验预览。
- 餐食图片不放右下角状态角标。
- 图片必须对应具体餐饮形态：酒窖应展示酒窖或品酒场景，丛林早餐应展示户外早餐桌与清晨荒野，星空晚宴应展示夜晚/星空/篝火/户外晚宴，特色烤肉应展示餐食或桌边服务。不要用门头、普通地图、树景或酒店大堂替代。

未购买体验可以在正文中写“可提前预约 / 可协助增订”，但必须同步写入费用不含。客户增订后，才转入正式行程与费用包含，并从费用不含删除。

自费、可选或待确认体验本身也可以是重要卖点，并可作为当天主图或主要体验卡。判断依据应是客户吸引力、路线相关性、画面价值和事实依据，而不是是否已经包含。展示时必须在对应正文或安静状态行中明确标注“自费可选 / 需提前预约 / 待确认”，并同步写入费用不含或待确认信息；不得把尚未购买的体验写成已含安排，也不得因为它是自费项目就自动降低图片优先级。

板块底部说明保持客户友好，不解释“图片用途”。推荐写法：

> 普通三餐以每日行程所列为准；特色餐饮、户外用餐及餐厅预约由酒店和营地结合当日运营安排。

### 5. 全程交通

交通板块要从奢游服务体验角度呈现，而不是简单写车名或车型广告。

每个交通卡应说明：

- 使用场景。
- 交通类别或车辆等级。
- 座位数或承载能力。
- 对舒适度、时间和衔接效率的具体贡献。
- 如有明确车型，才写具体车型；没有明确保证时不承诺品牌型号。

默认承诺车辆等级和座位数，不承诺具体品牌、型号或实际接待车队。交通图片可以是同等级服务示意，但底部统一说明边界。

推荐底部说明：

> 用车以约定车辆等级与座位数为履约标准；具体品牌及型号以当地实际调度为准。

不使用图片角标，不逐卡堆免责。

### 6. 每日行程

每日行程固定阅读顺序：

1. Day + 每日主题。
2. 今日路线：A → B → C。
3. 今日节奏：交通方式、移动时长、活动强度、必要休息安排。
4. 今日用餐。
5. 今晚入住：中文名 + 官方英文名。
6. 今日行程正文。
7. 今日贴士，确有必要时出现，最多一条。
8. 2 至 4 张对应体验图片卡。

每日正文以时间推进：

> 清晨 / 早餐后 / 午后 / 日暮 / 夜晚

正文必须包含客户动作或感官画面。不要只写“前往某地游览”，也不要把景点百科原样复制。

推荐写法：

> 客户会看到什么 + 为什么值得 + 奢游如何安排 + 这个体验在整条路线里的意义

自费、可选或待确认体验可以进入每日 `spots`、成为当天卖点并使用主图；但必须保留明确状态，并与费用不含或待确认信息一致。是否作为主图由销售价值、路线相关性和视觉质量决定，不以“已包含”作为唯一门槛。

### 7. 图片卡

图片卡必须服务当天行程，不能只是好看或“差不多”。
图片同时必须通过“奢华感/干净度/构图秩序”审核。即使图片内容真实相关，如果画面显得脏乱、廉价、烟熏、低清或容易让客户产生卫生疑虑，也不能进入顶奢客户版。

每张图片应承担一个明确角色：

- 地点本身。
- 核心活动方式。
- 代表性动物、地貌、文化或人物互动。
- 当天确有价值的酒店、交通或特色餐饮。

同一天的图片不能主题、机位和叙事作用都高度相似。

示例规则：

- 写塔兰吉雷国家公园，就要呈现塔兰吉雷、象群、猴面包树等核心卖点。
- 写 Mnemba 浮潜，就要呈现浮潜、珊瑚、热带鱼或海豚，不用泛泛海景替代。
- 写自由活动和 SPA，就可以呈现水疗、泳池、沙滩慢生活。
- 写同一张卡同时包含“丛林早餐与水疗可选”这类组合信息时，可以使用最多两张图片，每张分别对应一个明确子体验；如果采用单图，则优先表现更值得销售、且视觉更高级的体验。例如已有餐饮总览展示 Bush Breakfast 时，每日卡可改用酒店水疗中心、私人恒温泳池等高质感画面，避免重复与降级。
- 同一体验跨板块出现时，只保留一个主要图片展示位；其他位置改为简述，或把图片名额留给尚未展示且更有成交吸引力的体验。
- 写酒店体验，优先使用酒店官方媒体图。
- 写交通体验，展示外观、内舱或服务场景，而不是无关风景。

客户版图片卡不显示右下角状态角标。来源、授权、图片用途等信息只保存在内部记录，不显示给客户。

## 五、自然现象、提醒与安全规则

### 1. 今日贴士

每日行程里只保留一个可选“今日贴士”。只有确实能帮助客户准备时才出现，不为了版式硬凑。

推荐公式：

> 今天会遇到什么 + 建议怎么做

示例：

> 出海与下水时段会结合潮汐和海况安排，建议准备防晒、水母衣及防水收纳袋。

每日行程中不再堆叠“重要说明 / 安全须知 / 红色警告”。这些会打断购买情绪。

### 2. 自然奇观

迁徙、渡河、雪峰、天气、海况、热气球、野生动物等内容，不能冷冰冰地写成免责条款，也不能做保证承诺。

正确表达顺序：

> 先写为什么值得 → 再写常见季节或窗口 → 再写团队如何安排 → 最后温和说明边界

推荐示例：

> 每年7月至9月，角马大军通常会在马拉河区域集结。向导将结合兽群位置与河流水位选择守候区域；若当日未能遇见渡河，也请理解这正是野生迁徙最真实的魅力。

避免使用：

- “完全取决于自然节律”
- “具有不确定性”
- “以现场观察为准”
- “无法保证具体时间地点”

### 3. 注意事项

最终板块标题固定为“注意事项”，不要改成“安心出行”。

安全问题统一放在最终注意事项中，不拆到每日行程里。注意事项应覆盖：

- 行程与运营安排。
- 气候、穿着与健康。
- 游猎与营地安全。
- 海上活动与水上安全。
- 证件、财物与行李。
- 儿童、长者与特殊需求。

视觉和信息层级：

- 注意事项是收尾尾注，不是核心销售板块；视觉权重必须低于产品亮点、臻选下榻、全程交通和每日行程。
- 使用一个统一浅金色大容器承接所有内容，不把每个维度拆成独立大卡片。
- 板块分隔标题必须沿用整张长图统一的 English wordmark + 中文金色胶囊体系，不单独缩小或改变上下间距。
- 每个维度采用“小标题 + 一到两句短说明”，正文沿用整张长图的常规正文尺度，不出现突然变小的尾注感。
- 图标只做轻提示，避免大面积红色、强警告图标或连续警示框。
- 内容优先两列紧凑排布，通过统一容器、减少独立卡片和压缩重复文案控制整体高度，而不是通过过度缩小字号控制占比。
- 开头用服务型语气承接，例如“出发前请留意以下信息，定制师将在行前协助逐项核对。”

安全内容必须具体、可执行，并体现团队保障。比如：

- 国家公园及营地内请听从向导和工作人员安排，未经允许不得擅自下车或靠近、投喂野生动物。
- 夜间在野奢营地移动时，请联系工作人员陪同。
- 出海、浮潜及其他水上项目须听从船员与向导安排，并按要求穿戴救生及浮潜装备。

目的地治安、签证、健康政策等时效信息，生成时必须从权威官方来源复核。

## 六、费用表达规则

费用包含负责增强价值感，但不能让客户第一眼感觉“原来这些都是我额外付费买的清单”。表达要简洁、分类清楚、强调服务整合。

费用包含可按以下类别组织：

- 住宿。
- 交通。
- 门票。
- 司导。
- 餐食。
- 已含特色体验。
- 服务支持。

费用不含负责防纠纷，应明确但不抢走正文的销售情绪：

- 国际机票。
- 签证与保险。
- 小费。
- 个人消费。
- SPA、热气球等未购买体验。
- 未注明包含的升级项目。
- 客人临时变更或不可抗力产生的额外费用。

未购买体验必须“双处出现”：

- 正文中写有此服务，可提前预约或协助增订。
- 费用不含中写当前报价未包含。

客户购买后，应从费用不含删除，并加入费用包含或正式行程。

绝不展示供应商成本、内部利润、加价、汇率计算和内部备注。

## 七、事实、情绪与承诺边界

### 可以大胆表达

- 主观感受和旅行价值：人生必见、终生难忘、最壮观、最惊心动魄、旷野浪漫、绝世景观。
- 有场景支撑的情绪表达：星空下的晚宴、第一排守候迁徙、住进草原腹地、把时间交给印度洋。

### 必须有依据

- 全球唯一、世界第一、最大、最贵、仅有多少间、官方评级、奖项。
- 指定车型、指定房型、具体菜单、动物必然出现、渡河必然发生。
- 酒店设施、餐厅、活动开放时间、运营规则。

### 绝不能承诺

- 保证看到某种野生动物或自然现象。
- 未确认的免费升级。
- 未保证的专车品牌或车型。
- 未确认的私人包场或专属活动。
- 未经源数据确认的费用包含项目。

## 八、图片来源与文字联动

图片来源优先级：

> 用户原始资料图片 → 酒店 / 景区 / 运营方官方媒体 → 国家公园 / 旅游局 → 权威图库或可商用开放授权媒体

原始资料缺图时，必须按行程景点、酒店、餐食和交通服务分别搜索补齐。不能用相似但不对应当天主题的图片凑数。

搜索酒店时同步收集：

- 外观。
- 客房。
- 核心景观。
- 餐厅。
- 代表性用餐场景。
- SPA / 泳池 / 特色设施。

内部记录必须保留图片来源、授权类型、拍摄对象和使用模块；这些信息不显示在客户版卡片上。正式商业发布前应完成授权复核和必要署名。

## 九、报价表转长图流程

新收到原始报价单、供应商端表格或旧版行程资料时，必须按以下顺序处理。不要拿到表格后直接写长图正文。

### 1. 信息抽取

先把原始资料拆成结构化信息：

- 客户与行程基础信息：目的地、天数、人数、出行日期、客户偏好、特殊需求。
- 每日路线：城市 / 区域、A → B → C 路线、当天核心体验、是否自由活动。
- 酒店住宿：中文名、官方英文名、区域、晚数、房型、餐食计划、确认 / 参考 / 同级替换状态。
- 交通安排：接送机、跨城移动、内陆飞、船只、游猎车、商务车等级、座位数、是否承诺具体车型。
- 餐食安排：普通三餐、酒店 / 营地餐食、特色餐饮、可预约或自费升级餐饮。
- 体验状态：当前报价已含、可选自费、需提前预约、仅作推荐、不适合客户版展示。
- 费用边界：费用包含、费用不含、内部成本、供应商备注、利润或加价信息。
- 提醒信息：气候、运营季节、签证健康、行李、儿童长者、野生动物安全、水上活动安全。

### 2. 缺失与冲突检查

生成前必须先检查：

- 行程天数、每日编号、酒店晚数和路线是否一致。
- 酒店名称、英文名、房型、餐食计划是否缺失或前后矛盾。
- 交通等级、座位数、航班 / 船班 / 内陆飞信息是否足够客户理解。
- 正文、费用包含、费用不含之间是否冲突。
- 自费 / 可选体验是否同时在正文和费用不含中表达清楚。
- 是否存在客户不该看到的供应商报价、成本、利润、内部备注。
- 是否存在时效性信息，需要从权威来源复核。

如存在会影响客户理解、费用边界或履约承诺的缺失，必须先列出“待确认信息”，不得用想象补齐。

同时建立原始资料覆盖台账。原始表格中每个非空行、合并单元格或备注都必须归入“客户版展示、内部保留、重复合并、明确舍弃”之一，并记录去向或舍弃理由。逐日对账早餐、午餐、晚餐、活动、交通和住宿，不能只抽取醒目标题或海报亮点。

### 3. 分板块语言转换

信息抽取完成后，必须先把“原始资料语言”转换成“客户版表达语言”，再进入长图组件。抽取字段是事实层，客户文案是表达层，两者不得混用。

转换原则：

- 原始报价单的酒店、交通、餐食、景点、注意事项描述不得直接复制进客户版。
- 每个板块必须根据自身目的重写：产品亮点负责激发购买欲，行程总览负责快速理解，臻选下榻负责证明住宿价值，特色餐饮负责呈现用餐氛围与餐桌记忆点，全程交通负责说明舒适衔接，每日行程负责让客户看见当天体验，注意事项负责专业兜底。
- 供应商提供的“包含 / 不含 / 备注 / 注意 / 参考”等字段必须先判断客户可见性，再转换成对应板块语言。
- 内部成本、利润、操作备注、供应商沟通信息不得进入客户版。

板块转换方向：

- 产品亮点：从“去了哪些地方”转换为“为什么这条路线值得选、为什么由奢游来做更好”。
- 行程总览：从“每日完整安排”转换为“路线主线 + 当日主题”，删除重复餐食和酒店长名。
- 臻选下榻：从“酒店设施和位置罗列”转换为“位置价值 + 私密感 / 景观 / 服务 / 路线节奏”。
- 特色餐饮：从“三餐清单”转换为“特色餐饮、酒店餐厅和代表性用餐场景”；普通三餐不做图片化销售。
- 全程交通：从“车型或接送描述”转换为“车辆等级、座位数、舒适度、时间衔接和专属服务感”。
- 每日行程：从“流水账”转换为“今日路线预览 + 时间推进 + 值得体验的现场画面”。
- 注意事项：从“红色警告和免责堆叠”转换为“定制师提前帮客户想到的小提醒”，语气温和、具体、可执行。
- 费用包含 / 不含：从“成本清单”转换为“服务整合说明 + 防纠纷边界”，不削弱正文购买欲。

### 4. 内容生成顺序

通过抽取与检查后，再进入客户版写作：

1. 先生成路线骨架，再写每日情绪主题。
2. 先写产品亮点，再写总览，不要从每日流水账开始。
3. 行程总览只承担“一眼看懂路线与主题”的作用，不重复餐食和酒店长名。
4. 酒店、特色餐饮、全程交通先于每日细节展示，让客户在进入细节前知道住什么、怎么走、吃什么。
5. 按时间顺序写每日正文，把百科知识压缩进体验语境。
6. 将安全和履约边界集中放入最终“注意事项”，每日只保留确有必要的“今日贴士”。

### 5. 图片任务清单

写作同时必须建立图片清单：

- 为每一天分配互不重复的图片角色。
- 景点图片必须对应当天路线和核心卖点，不能只用“相似氛围图”凑数。
- 酒店缺图时优先搜索酒店官网、官方媒体图库或品牌官方渠道。
- 餐食缺图时优先搜索酒店 / 营地官方餐厅、代表性用餐场景或特色餐饮图片。
- 交通缺图时可使用同等级服务示意图，但必须符合车辆等级、座位数和使用场景。
- 图片来源、授权类型、拍摄对象和使用模块只登记在内部记录，不显示在客户版卡片上。
- 图片登记状态分为“正式使用、候选备用、已淘汰”；淘汰项记录脏乱、错位、重复、画质不足等原因，后续自动选图不得再次把已淘汰素材当作正式候选。
- 更换图片对象时，必须同步重审卡片标题、正文、状态标签和费用边界，避免只换图而保留旧文案。

### 6. 生成前最终验收

正式生成长图前，必须完成以下复核：

- 英文酒店名、确认状态、同级替换说明是否合规。
- 酒店、交通、餐食、每日行程和注意事项是否都已完成客户版语言转换，没有照搬原始表格描述。
- 未购买体验是否同时写入正文与费用不含。
- 费用包含是否强调服务整合和价值感，而不是像付款清单。
- 费用不含是否防纠纷但不破坏正文销售情绪。
- 图片是否与每日路线、酒店、交通、餐食强相关。
- 语言是否符合奢游品牌表达，保留向往感、稀缺感和场景感。
- 注意事项是否完整但低权重，标题、字号和间距不脱离整张长图体系。
- 是否清除所有内部成本、利润、供应商备注和客户版禁用词。
- 产品亮点是否保留1—2条奢游通用服务优势，并把主要篇幅留给路线独有卖点；亮点之间不得换词重复。
- `layout: "wide"` 是否优先给路线独有、稀缺、销售价值高且图片质量高的核心卖点，而不是按数据顺序放大最后一项；如该卖点属于自费、可选或待确认体验，是否已明确标注状态并同步费用边界。
- 所有隐藏字段、空指标和被删除卡片是否同步收缩版面，没有预留无意义的固定空白。
- 是否只生成并交付一张2000px客户高清版；复合体验双图在该成品中是否逐张可辨认。

## 十、验收清单

- 读完是否让人产生出发冲动，而不是只获得信息？
- 是否能看出路线经过设计，而不是景点拼接？
- 是否用具体场景证明奢华，而不是只喊“顶奢”？
- 产品亮点是否同时包含奢游公司优势和该路线差异？
- 行程总览是否足够清爽，没有重复餐食和酒店长名？
- 酒店客户卡是否保留官方英文名、区域、晚数和住宿价值表达，并避免直接展示房型/餐食/报价标签？
- 交通是否承诺等级与座位数，而不是无依据承诺具体车型？
- 特色餐饮是否只展示特色餐饮或代表性餐饮场景？
- 每日行程是否有路线预览、时间推进和客户体验画面？
- 图片是否与当天路线和卖点强相关，没有同义重复？
- 是否保留了奢游旧版富有感染力的高情绪词汇？
- 自然奇观是否保留吸引力，同时把边界温和说清楚？
- 未购买项目是否在正文与费用不含中同时出现？
- 每日是否只保留必要的“今日贴士”，没有硬凑提醒？
- 最终是否使用低权重、紧凑尾注式“注意事项”，并覆盖安全、健康、行李、海上活动等客户关心的问题？
- 是否清除了内部成本、利润、供应商备注和客户不该看到的信息？
