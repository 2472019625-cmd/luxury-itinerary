# 长图生成说明

> **历史迁移文件**：当前有效内容已迁入 `06-技术运行与文件保存.md`，2000px 交付规则迁入 `05-模板版式与品牌资产.md`。本文件仅供历史命令追溯，不再作为当前执行依据。

## 预览

```powershell
npm run dev -- --host 0.0.0.0 --port 4173 --strictPort
```

## 输出 PNG

保持预览服务运行，然后执行：

```powershell
npm run render
```

标准交付只生成 2000px 宽客户高清版；高度自动随内容增长。2000px既是设计坐标母版，也是正式客户稿，可减少细字、餐饮细节和车辆内饰在发送及二次压缩后的模糊。1080px仅保留为特殊渠道需要时的可选输出，不再日常同时生成。输出位于 `workspace/output/`。

若浏览器不在默认路径，可设置任务专用环境变量：

```powershell
$env:LUXURY_TRAVEL_BROWSER='D:\Browser\chrome.exe'
```

后续扩展 A4 PDF 时，建议新增分页样式，不直接把超长 PNG 切页；保持 DOM 文字和 SVG 图标为矢量内容。
