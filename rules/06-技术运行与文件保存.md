## 标准命令入口

`simple-skill-pipeline` 不保存或执行 finding package、`review_decision`、Reviewer→Agent→Retry、多层审核、自动业务重搜或 stage budget 驱动流程。运行记录只需保存实际输入、责任单元、能力结果、确定性错误、文件结果、耗时及必要技术诊断，不得保存模型隐藏思维链。单个责任单元失败只影响该单元并允许无依赖任务继续；只有主输入无法解析、核心事实结构无法建立、关键事实/费用无法继续、项目保存失败或其他使所有后续任务无法继续的项目级错误才中断整条链。

从 `app/` 执行：`npm run test:import`、`npm run test:rules`、`npm run test:images`、`npm run test:sites`、`npm run test:dynamic`、`npm run test:africa`、`npm run build`。具体任务只运行交接稿要求的集合，不以测试通过替代真实验收。

## 智能体第一版补充资料边界

主行程仍只能是一份受支持的 Excel。补充资料白名单为可提取文本的 PDF、DOCX、TXT、Markdown，以及用户明确授权的图片；这些资料只提供补充文本证据，不能覆盖 Excel 或用户已确认事实。第一阶段影子规划器只记录资料类型、来源和用途，不实现真实解析。扫描件 OCR、旧 `.doc`、聊天记录和任意文件主输入不在第一版范围；文本提取失败时要求用户粘贴文字或提供可读文件，不猜测内容。
