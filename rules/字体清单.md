# 字体清单

> **历史迁移文件**：当前有效内容已迁入 `05-模板版式与品牌资产.md`。本文件仅供资产迁移核对与历史追溯，不再作为当前执行依据。

品牌规范指定：品牌专用中文字体优先使用思源宋体与思源黑体系列，英文使用 Poppins；品牌推广主标题可使用风雅宋体。风雅宋仅作为推广展示字体，不替代品牌专用字体。

当前嵌入结果：

- 思源黑体 CN：已嵌入 ExtraLight、Light、Normal、Regular、Medium、Bold、Heavy，并保留 LICENSE。
- Poppins：已嵌入 Light、Regular、Medium、SemiBold、Bold、ExtraBold，并保留 OFL.txt。
- 猫啃网风雅宋：已嵌入常规字体，并保留 License.txt；仅用于品牌推广大标题或经确认的 Slogan 展示，不用于正文、DAY信息、表格、报价、标签和图片说明。
- 思源宋体 CN：已嵌入 ExtraLight 至 Heavy 全七字重及 LICENSE，作为扩展标题字体资源。
- Microsoft YaHei：仅作为系统级故障回退，不再用于正常渲染。

字体源文件与授权统一保存在 `assets/fonts/`。模板通过 `app/src/styles.css` 的 `@font-face` 加载 `app/public/fonts/` 中的运行副本；根目录源文件是维护依据，`app/public/fonts/` 只服务于程序运行。
