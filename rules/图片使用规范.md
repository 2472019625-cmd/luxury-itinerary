本文件是奢游行程报价单自动生成流程的必读规则。每次生成、改写、替换或补充行程报价单图片前，都必须先读取并执行本文件；它不是普通参考资料，而是最终输出选图规则。

## 1. 核心影像调性

奢游品牌影像应同时呈现四个核心特质：

- 奢华：画面能体现高端度假、精品酒店、私密空间、定制服务或稀缺体验。
- 快乐：人物或场景传递轻松、享受、愉悦、松弛的度假状态。
- 品质：构图、光线、色彩、清晰度、场景细节都应有高级感。
- 独特：避免普通旅游打卡图，优先选择有目的地辨识度、酒店特色或体验记忆点的图片。

整体风格应豪华大气、自然真实、色彩浓郁但不过度艳丽，避免廉价感、网红感、游客感和过度商业素材感。

## 2. 图片优先级

选图时按以下优先级判断：

1. 与行程节点强相关：图片必须能对应目的地、酒店、活动、餐饮、交通或服务场景。
2. 符合奢游品牌调性：即使内容相关，如果画面廉价、杂乱、普通，也不应使用。
3. 具备视觉吸引力：优先选择构图开阔、主体明确、光线柔和、质感突出的图片。
4. 能帮助客户想象体验：图片不只展示地点，还要让客户感受到“我会在那里如何度假”。
5. 与版面功能匹配：封面、日程页、酒店页、体验页、报价页所需图片类型不同，不能混用。

## 3. 不同版块选图规则

### 封面图

封面图必须代表整份行程的最高吸引力。

优先选择：

- 目的地最具代表性的奢华度假场景。
- 顶级酒店、私人别墅、游艇、雪山、海岛、沙漠、极地等具有强记忆点的画面。
- 横向大图，构图开阔，适合承载标题文字。
- 画面中可以有人，但人物不能抢过目的地或体验本身。

避免选择：

- 普通城市街景、拥挤景区、自拍感人物照。
- 主体过小、过乱、过暗或无法快速识别目的地的图片。
- 与本次行程无关的纯氛围图。

### 行程总览图

行程总览图用于建立整体期待感。

优先选择：

- 能串联目的地气质的自然景观、酒店外观、核心体验图。
- 多目的地行程中，每个重要目的地至少有一张代表图。
- 色调统一、节奏相近的图片组合，避免同一页出现强烈割裂。

避免选择：

- 过多人物特写。
- 色温和风格差异过大的图片混排。
- 与常规旅游宣传图雷同、缺少奢华识别度的图片。

### 每日行程图

每日行程图应准确对应当天内容。

优先选择：

- 当天核心活动的真实场景，如出海、滑雪、潜水、高尔夫、瑜伽、文化参观、美食体验。
- 人物处于自然享受状态的图片，动作优雅、表情轻松。
- 同一天中如有酒店、活动、餐饮三类内容，优先展示最能打动客户的体验图。

自费、可选或待确认体验可以成为当天主图。选图优先级由该体验的销售吸引力、路线相关性、目的地辨识度和画面质量决定，不因“当前报价未包含”自动降级；但相邻正文或状态行必须明确说明“自费可选 / 需提前预约 / 待确认”，并与费用不含或待确认信息一致。

避免选择：

- 只好看但无法对应当天安排的图片。
- 过于抽象、无法说明行程内容的图片。
- 人物情绪紧张、疲惫、尴尬或表演痕迹过重的图片。

### 酒店与别墅图

酒店图要体现“为什么这家值得选”。

优先选择：

- 酒店外观、海景/山景/泳池/庭院、套房、私人露台、餐厅、水疗等高价值空间。
- 空间干净、材质高级、光线柔和、视野开阔的图片。
- 能体现私密性、定制感和稀缺景观的图片。

避免选择：

- 普通客房角度、杂乱餐厅、低质官方小图。
- 无法体现酒店等级的局部细节。
- 人流密集、服务混乱或设施老旧的画面。

### 活动体验图

活动体验图要让客户感到“这不是普通项目，而是奢游式体验”。

优先选择：

- 游艇、私人沙滩、雪山滑雪、海岛潜水、沙漠营地、酒庄晚宴、主厨餐桌、直升机、私人导览等体验。
- 有参与感但不过度摆拍的画面。
- 能体现舒适、安全、专业服务和稀缺性的图片。

避免选择：

- 普通旅行团、排队、人群密集、商业化过重的活动照片。
- 动作粗糙、设备廉价、环境杂乱的体验照。

### 餐饮与服务图

餐饮和服务图应表达精致、周到、专业。

优先选择：

- 主厨、私宴、酒水、餐桌布置、服务人员、茶歇、欢迎礼等细节。
- 人物着装得体，服务动作自然专业。
- 食物和空间都清晰、有质感。

避免选择：

- 油腻、廉价、过曝或摆盘混乱的食物图。
- 容易产生卫生疑虑的烟熏烤炉、脏乱桌面、杂物堆叠、粗粝炉火近景，即使属于真实餐厅也不进入顶奢客户版。
- 服务人员表情紧张、姿态随意或画面不专业的图片。
- 只与地点相关、但无法对应餐饮内容的门头、外景、空镜或普通酒店大堂。
- 用普通餐桌替代星空晚宴、用普通树景替代丛林早餐、用泛化酒吧替代私人酒窖等“文字与画面不对应”的图片。

特色餐饮必须优先匹配具体体验形态：

- 私人酒窖/品酒：优先展示酒窖、酒柜、品酒桌或酒店官方酒窖空间。
- 丛林早餐/Bush Breakfast：优先展示户外早餐桌、清晨草原餐桌、早餐食物与荒野环境。
- 星空晚宴/Boma/Bush Dinner：优先展示夜晚、星空、篝火、户外晚宴或营地仪式感餐桌。
- 特色烤肉/主题餐厅：优先展示实际餐食样式、桌边服务或烤肉呈现方式；门头只能作为无更好素材时的备选。
- 餐厅本身风格偏热烈或市井时，选图必须用构图、裁切和光线把重点放在“干净餐食、服务动作、餐桌体验”，避免放大杂乱环境。

### 交通图

交通图用于说明出行等级与舒适度，不承诺具体车牌、车辆、机型或船型，除非业务源数据明确保证。

优先选择：

- 同等级或同类别的车辆外观、内饰、游猎车、游艇、包船、小飞机、直升机等真实图片。
- 画面干净、空间宽敞、座椅与服务细节清晰。
- 能体现私密接送、舒适转场、专业安排的图片。

避免选择：

- 低端车辆、脏乱内饰、拥挤公共交通。
- 与实际交通类别不一致的图片。
- 容易让客户误以为承诺具体品牌型号的误导性表达。
- 用酒店大堂、机场大厅、纯风景图代替商务车、游猎车、小飞机或船只本身。

交通图必须让客户一眼看懂交通类别：

- 商务车：展示商务车外观、内饰、座椅空间或外观+内饰组合。
- 游猎车：展示开顶或同等级 Safari 车辆，最好有草原、向导、观察或摄影情境。
- 草原小飞机：展示轻型飞机、登机、跑道或空中衔接场景。
- 船只/出海：展示船型、码头登船、海上航行或服务场景。

## 4. 色调与光线标准

图片色调应处于暖色、自然、低调奢华的范围内。

优先选择：

- 自然采光、日出日落、柔和侧光、室内暖光。
- 色彩浓郁但不过饱和，整体干净、稳定、耐看。
- 天空、海水、植被、木质、石材等自然色表现良好。

避免选择：

- 强烈滤镜、荧光色、过度 HDR、网红调色。
- 阴暗压抑、灰脏、过曝、死白或噪点明显的图片。
- 闪光灯直打导致人物或空间失去高级感的图片。

## 5. 人物影像标准

人物可以出现，但必须服务于度假体验。

优先选择：

- 人物状态优雅、自然、放松，体现享受、快乐、松弛和品质生活。
- 动作可以是散步、阅读、品酒、美食、瑜伽、游泳、出海、观景等。
- 人物占比适中，最好与场景形成关系，而不是单纯自拍。
- 服务人员应专业、热情、周到，服装整洁，动作规范。

避免选择：

- 自拍、大头照、夸张表情、游客打卡姿势。
- 抽烟、酗酒、疲惫、焦虑、争吵等不健康或负面状态。
- 与品牌无关、形象违和、过度性感化或过度表演的人物形象。
- 人脸模糊、焦点不清或人物被尴尬裁切的图片。

## 6. 场景选择标准

场景必须真实可信，同时有高级品质。

优先选择：

- 海滩、雪山、森林、沙漠、湖泊、古城、庄园、酒庄、寺庙、博物馆、精品酒店、私人别墅、游艇、营地等。
- 室内场景应体现定制化装饰、材质质感、空间秩序和服务细节。
- 室外场景应构图宏大、主题明确，能让人沉浸其中。

避免选择：

- 生活杂乱、背景复杂、拥挤吵闹的环境。
- 缺乏真实性的 AI 感、模型感或超现实场景。
- 与常见旅游图片雷同、没有识别度的景观。

## 7. 禁用图片类型

以下图片不应用于奢游报价单和行程单最终输出：

- 无明确主题，过于抽象。
- 与旅游、度假、酒店、目的地或服务无关。
- 环境杂乱，背景复杂。
- 画面模糊，焦点不清。
- 镜头畸变严重，人物或建筑变形。
- 缺乏真实性，明显 AI 感或超现实。
- 与普通旅游场景雷同，缺少品牌特质。
- 过度夸张、猎奇、低俗或网红感。
- 与品牌无关的人物形象。
- 人物形象违和、妆造夸张、表情尴尬。
- 抽烟、酗酒、争吵、疲惫、紧张等负面或不健康行为。
- 人物表情痛苦、焦虑、不快乐。

## 8. 技术与版面要求

- 主视觉使用 16:9 槽位；单图为 16:9；双图、四图为 4:3；三图使用一大两小组合。
- 使用 `object-fit: cover`，禁止拉伸。默认焦点 `50% 50%`，可通过 `focus` 字段调整为如 `50% 35%`。
- 当图片是商务车外观+内饰拼图、房间结构图、餐饮细节组合、竖向餐饮服务图等信息密度高的素材时，可设置 `fit: "contain"` 并搭配合适卡片比例，优先保证客户能看清主体。
- 复合体验允许在同一卡片使用两张图片，但每张图片必须通过 `images[].label` 分别对应一个明确子体验，例如“丛林早餐 + 水疗”分别使用早餐场景与水疗空间。禁止无对应关系的装饰拼贴，客户卡最多两图。
- 复合体验双图必须在最终 2000px 客户高清版中逐张检查；任一主体无法独立辨认时，应拆为两张卡、改用宽卡，或只保留更值得销售的一项，不以增加图片数量代替清晰表达。
- 全图旅行图片必须全局去重。封面、酒店、特色餐饮、交通、每日行程之间不得重复使用同一文件、同一视觉裁切或同一来源照片。
- 推荐源图不低于 2400px 长边，sRGB，JPEG 品质 85% 以上或无损 PNG/WebP。
- 景点图、名称和介绍必须放在同一 `spot` 对象中，避免错位。
- 酒店、餐饮、交通等分区图片必须与对应对象绑定，不得跨对象误用。
- `assets/placeholders/` 为无版权文本的测试占位素材，不代表真实目的地，不应作为正式业务图片发布。
- 过长介绍优先增加卡片高度；若业务要求截断，应在数据清洗阶段添加“……”并保留完整原文。

## 9. 最终输出前检查清单

每张进入最终报价单、行程单的图片，至少满足以下条件：

- 内容相关：能对应本次行程、目的地、酒店或体验。
- 调性正确：体现奢华、快乐、品质、独特中的至少两项。
- 画质合格：清晰、无明显噪点、无严重压缩、无水印。
- 光线舒适：自然柔和，不过暗、不过曝、不廉价。
- 构图稳定：主体明确，适合当前版面裁切。
- 人物得体：如有人物，状态自然、优雅、正向。
- 风格统一：与同一份文件中的其他图片色调和气质一致。
- 无禁用项：不含杂乱、模糊、抽象、违和、负面行为等问题。
- 来源留痕：正式输出前必须记录来源、授权、摄影师或官方媒体说明。
- 全局唯一：同一份客户长图内旅行图片不得重复出现。
- 图文对位：每张图片必须和所在卡片标题、正文体验逐一对应，不能只做到目的地相关。
- 双图可读：复合体验的两张图片在 2000px 成品中均能独立辨认，并与两个子体验一一对应。

## 10. 推荐评分法

当同一位置有多张候选图时，可按 5 个维度打分，每项 1-5 分，总分 25 分。

| 维度 | 判断标准 |
| --- | --- |
| 相关性 | 是否准确对应行程内容、目的地或酒店 |
| 奢华感 | 是否体现高端、私密、稀缺、精致 |
| 情绪感 | 是否传递快乐、松弛、享受、期待 |
| 品质感 | 光线、构图、色彩、清晰度是否高级 |
| 独特性 | 是否区别于普通旅游图片，有记忆点 |

使用建议：

- 22-25 分：优先用于封面、章节页、重点酒店或核心体验。
- 18-21 分：可用于正文行程、酒店说明、活动介绍。
- 15-17 分：仅在素材不足时作为补充图。
- 15 分以下：不进入最终输出。

## 11. 自动化选图提示词

如后续在自动化流程中调用模型或图像检索，可使用以下规则提示：

请为奢游高端定制旅行报价单/行程单选择图片。图片必须与当前行程节点高度相关，并符合“奢华、快乐、品质、独特”的品牌调性。优先选择自然采光、色调温暖或自然、构图开阔、主体明确、质感高级、能体现度假享受或高端服务的真实图片。避免普通游客照、杂乱环境、模糊画面、过度滤镜、廉价网红感、AI 感、负面人物状态、抽烟酗酒等不健康行为，以及与目的地或行程无关的抽象图片。输出时按相关性、奢华感、情绪感、品质感、独特性五项评分，并说明推荐使用位置。

## 12. 图片使用位置建议

| 使用位置 | 首选图片类型 | 关键要求 |
| --- | --- | --- |
| 封面 | 目的地大场景、顶级酒店、稀缺体验 | 高记忆点、横向构图、可承载标题 |
| 行程概览 | 目的地组合、酒店外观、核心体验 | 风格统一、建立期待 |
| 每日行程 | 当天活动、景点、体验 | 内容准确、体验感强 |
| 酒店介绍 | 外观、套房、泳池、露台、餐厅、水疗 | 体现等级和私密性 |
| 活动介绍 | 游艇、滑雪、潜水、私宴、导览 | 体现稀缺和参与感 |
| 餐饮服务 | 主厨、餐桌、酒水、服务人员 | 精致、专业、温暖 |
| 交通介绍 | 同类别交通外观/内饰/转场体验 | 体现舒适度，不误导承诺 |
| 报价页/尾页 | 低干扰氛围图或品牌质感图 | 不抢信息、保持高级感 |

## 13. 自动搜索、三态审核与人工确认

本节是自动图片搜索、模型审核和人工采用流程的强制规则。自动审核不得把“首选画面”或“理想构图”当成唯一可用画面的硬门槛，也不得仅因单项分数低于固定阈值就让候选图片从用户视野中消失。

### 13.1 审核结果必须使用三种状态

每张进入审核的候选图片必须得到以下一种结果，并保留在内部候选记录中：

- `自动通过`：没有硬性风险，主体与图片位相符，来源、画质和整体调性足以直接进入客户草稿。
- `待人工确认`：没有明确硬伤，但场景不是首选、来源与画面判断存在不确定性、奢华度或构图一般，仍可能满足业务使用需要。
- `明确拒绝`：存在不可接受的硬性问题，不得自动进入客户成品。

系统不得把所有未达到“最佳画面”的图片直接归为 `明确拒绝`。当图片没有硬性问题但不够理想时，必须进入 `待人工确认`。

### 13.2 硬门槛与软偏好必须分开

以下属于硬门槛，命中任一项时可判定为 `明确拒绝`：

- 图片无法加载、解码失败、分辨率或比例不满足成品最低要求。
- 存在明显媒体水印、网址、版权角标、后期覆盖的摄影师署名或无权使用的标识。
- 主体类别完全错误，例如草原飞机图片位出现角马渡河图，酒店图片位出现鸟类或机构 Logo。
- 来源或画面能够明确证明酒店、目的地、活动地点错误。
- 画面明显脏乱、低档、失焦、严重变形或不适合客户成品。
- 与同一份客户长图中的已采用图片构成文件级或视觉级重复。

以下属于软偏好，只用于排序和推荐，不得单独作为硬拒绝理由：

- 酒店外观、泳池或花园优于大堂、客房等其他真实高品质酒店空间。
- 日出、日落或理想天气优于普通白天光线。
- 画面留白、横向构图和默认裁切适配程度。
- 同类候选之间奢华感、情绪感和独特性的高低。
- 画面是否包含未被客户文案明确承诺的装饰性元素，例如香槟、鲜花或摆台细节。
- 图片是否完全符合搜索时描述的首选镜头；只要核心主体和业务含义正确，非首选镜头仍可进入 `待人工确认`。

评分用于候选排序、解释和分流，不能替代硬门槛判断。不得用一个统一分数同时决定酒店、交通、餐饮、封面和每日体验图片的生死。

### 13.3 来源证据与视觉判断必须分别记录

每张候选图至少记录：来源页面、原图地址、来源类型、是否官方来源、图片主体、相关性、清晰度、干净度、奢华感、初审理由和终审理由。

- 酒店官方网站或酒店官方媒体中的真实酒店空间，应获得较高的酒店身份可信度。模型不得仅凭山形、建筑风格或主观印象，推翻可信官方来源并武断判断为其他国家或酒店。
- 官方来源不能替代视觉主体核查。官方酒店页面中的餐厅图不能自动用于泳池文案，酒店 Logo 或宣传海报也不能替代真实空间图。
- 第三方来源不能只因标题包含酒店品牌而视为官方来源；继续依据域名和来源页面判断。
- 当来源证据可信但视觉场景不是首选时，优先进入 `待人工确认`，而不是 `明确拒绝`。

### 13.4 不同模块使用不同判定口径

- 封面：目的地辨识度、画质、构图和标题承载能力是核心；具体酒店或单一体验不是默认硬要求。
- 酒店：酒店身份和来源必须可靠；外观、客房、大堂、泳池、花园、餐厅、水疗等真实高品质空间均可成为候选。只有客户文案明确承诺某一设施时，该设施才升级为必须匹配的主体。
- 特色餐饮：必须匹配用餐类型和环境。香槟、特定菜品或仪式细节只有在原始事实或客户文案明确出现时才是硬要求，否则只是加分项。
- 交通：交通工具类别必须正确；品牌、车型、机型和内饰只有在源数据明确保证时才是硬要求。
- 每日体验：当天核心活动主体必须匹配；普通目的地风景不能替代明确的游猎、飞行、渡河、潜水、晚宴等活动。

### 13.5 人工确认流程

当某个图片位没有 `自动通过` 图片，但存在 `待人工确认` 候选时，生成流程必须在进入编辑器之前提供图片确认步骤：

1. 展示候选缩略图、来源页面、官方来源标识、主要评分、进入待确认的原因和已知风险。
2. 用户可以选择 `采用此图`、`拒绝此图`、`本图片位留空`，或上传已确认且具备使用权的本地素材。
3. 用户采用待确认图片时，系统记录人工决定、时间和原始审核风险，不得把它伪装成模型自动通过。
4. 对明显媒体水印、主体完全错误、明确地点错误、破图、低分辨率和全局重复图，不提供直接采用入口；如用户拥有无水印或已授权版本，应上传替代文件。
5. 人工选择不得被后续后台结果、重新轮询或自动分配无条件覆盖。

### 13.6 生成完成口径

只有所有图片位都形成最终结果后，生成任务才能达到 100% 并允许进入编辑器。图片位最终结果包括：

- 已采用自动通过图片。
- 已采用人工确认图片。
- 用户明确选择留空。
- 搜索或审核失败，且不存在待处理候选。
- 所有候选被明确拒绝，且不存在待处理候选。

只要仍有 `待人工确认`、搜索中、审核中或分配中的图片位，就不得进入编辑器。图片位处理完成不等于必须找到合格图片；严格审核后可以留空，但必须向用户说明最终状态和原因。
