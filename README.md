# 奢游行程单美化本地工具

> 当前身份：奢游行程单美化本地工具的唯一开发源。  
> 当前路径：`D:\奢游\行程单报价单\奢游行程单美化-本地版`  
> 冻结历史项目：`D:\奢游\行程单报价单\奢游行程模板系统`，只允许查阅和恢复，不再修改代码。

本项目是将供应商 Excel 行程报价转换为客户版 2000px 长图的本地工具。当前客户长图视觉基准为 `assets/references/current-visual-baseline-kenya-8d-2000.png`；它约束整体风格、结构、密度和阅读节奏，但不覆盖原始数据事实、文案规则、图片合规规则或缺陷验收标准。当前有效规则入口见 `rules/00-当前规则索引.md`。

## 目录

```text
奢游行程单美化-本地版/
├─ app/          程序运行文件、依赖、构建产物和内部技术资源
├─ assets/       品牌资产、字体源文件与当前视觉基准
├─ rules/        当前正式规则与规则迁移对照表
├─ workspace/    项目工作数据、图片账本和生成结果
├─ audit/        验收问题、任务书、交接记录和证据
├─ tests/        自动测试入口（连接到 app/tests）
├─ AGENTS.md
├─ README.md
└─ 启动工具.cmd
```

根目录只负责让人快速找到内容；程序内部技术文件统一收在 `app/`。`app/output` 和 `app/.jobs` 是分别指向 `workspace/output` 与 `workspace/jobs` 的本地连接，用于保持现有程序稳定，不形成第二份数据。品牌源文件统一放在根目录 `assets/`，程序实际加载的浏览器资源放在 `app/public/`。

## 快速使用

1. 本机配置文件位于 `app/.env.local` 和 `app/.env.image-search.local`。
2. 双击根目录 `启动工具.cmd`，打开 `http://127.0.0.1:4173/`。
3. 上传 Excel，确认识别结果后等待文案、真实图片和 2000px 长图生成。
4. 技术回归命令从 `app/` 目录执行。

启动器会在后台保持服务运行并自动打开浏览器，日志写入 `workspace/output/server.log` 与 `workspace/output/server-error.log`。

## 图片流水线

系统使用智谱 Web Search 获取网页来源，再从官网或来源页提取原图；公共目的地与野生动物场景可回退到 Wikimedia Commons。下载后依次执行尺寸/MIME 校验、SHA-256 精确去重、感知哈希相似图去重、GLM 候选排序和单图终审。主体、地点、水印、整洁度或高端感不合格时不会强行填图。

选用来源与淘汰原因保存在 `workspace/output/image-ledgers/`，图片保存在 `workspace/output/image-assets/`。来源记录用于追溯，不代表自动取得商业使用授权，正式发布前仍需复核媒体许可。

正式品牌字体已嵌入，详见 `rules/字体清单.md`。每次自动生成或替换报价单/行程单图片前，必须先读取 `rules/图片使用规范.md`；图片采用联网搜索与授权核对优先策略，来源记录见 `audit/图片来源.md`。投产前仍须将真实账户、联系方式和图片替换为经业务确认的数据。

## 版本管理

- `main` 保存当前稳定、可运行的版本。
- 每个正式任务从 `main` 创建一个独立分支，完成测试和确认后再合并。
- 分支按任务类型命名，例如 `feat/酒店模块编辑`、`fix/图片搜索超时`、`docs/规则更新`。
- 提交说明写清楚实际结果，例如“修复图片超时后任务无法完成”，避免只写“修改代码”。
- `workspace/` 下的运行数据、本地密钥和原始验收证据不上传 GitHub；任务书、问题台账和验收结论继续进入版本历史。
